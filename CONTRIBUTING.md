# Contributing

## Commit messages

This project uses [Conventional Commits](https://www.conventionalcommits.org/).
See [COMMITS.md](https://github.com/fullsend-ai/fullsend/blob/main/COMMITS.md)
for the full specification, type selection rules, and examples.

Pull request titles must follow the same Conventional Commits format.

## DCO

Use `git commit -s` so every commit includes a `Signed-off-by` trailer.
